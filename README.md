# Aloud

Aloud is a one-button visual assistant for blind and low-vision people, with a simple mode for people with cognitive disabilities. Point your phone and press once. Aloud reads text, describes what is in front of you, names objects, walks you through a task one step at a time, and remembers where you put things.

It says when it is not sure, and tells you how to move the camera so it can be.

> Work in progress for the Nebius x NVIDIA Global AI Hackathon (Personal AI track). Setup, models and evaluation are documented as they land.
